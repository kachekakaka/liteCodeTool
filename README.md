# Lite Code Tool (轻量代码工具)

轻量、极简且易于扩展的代码辅助与处理工具。坚持实用主义设计与轻量化工程标准，杜绝过度治理。

---

## 文档导航

开发入口见 [快速开发手册](./快速开发手册.md)，日常操作见 [快速入门手册](./快速入门手册.md)。前端使用 Vue Router 管理资源地址，开发与发布统一使用 Vite；内网环境使用完整离线开发包。

## 核心设计原则

1. **轻量实用，杜绝过度治理**：
   - 坚决不引入重型测试体系（无复杂 UI E2E、无大型流水线门禁）；
   - 仅对底层关键核心算法、代码解析或数据转换保留短小精悍的纯函数单测。

2. **三层物理隔离体系**：
   - **代码核心仓**（`liteCodeTool/`）：保持高度纯净，仅包含源代码、长期受控文档与工程配置；
   - **外部临时空间**（`../liteCodeTool_tmp/`）：吸收所有临时日志、构建中间物与实施报告双写镜像；
   - **外部数据空间**（`../liteCodeTool_datas/`）：存放运行时动态生成的用户配置与业务持久化数据。

3. **受控演进，先问再做**：
   - 复杂改造前置征询用户是否需要方案；方案经确认后落盘 `docs/方案/`，实施闭环后自动归档至 `archive/docs/方案/`。

## 开发与协作约束

所有参与本项目的开发者与 AI Agent 须严格遵守 [`AGENTS.md`](./AGENTS.md) 所定义的协作红线（包括未获授权不写代码、双写镜像落盘、Windows 下 Git 提交防乱码规范等）。
