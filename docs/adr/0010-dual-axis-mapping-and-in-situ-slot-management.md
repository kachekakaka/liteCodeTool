# 0010. 自由双轴映射、就地槽位管理与全模式换船

为解决组件工坊在数据绑定流程中的层级割裂、死板“对象1”占位符无法就地新建重命名、工坊预览产生具体实体写死误解、编辑态缺失就地换船入口，以及全局 KPI 指标卡内容上下超边问题，系统确立数据类型优先、就地槽位联动、双轴自由映射、工坊图例脱敏、全模式悬浮换船以及 KPI 垂直排版防超边全套架构契约。

## 决策背景与核心权衡

1. **时序走势与空间轨迹的统一动力学模型（Dual-Axis Mapping）**：
   - 拒绝重型切分多个独立散点图/轨迹图组件，复用轻量 SVG 图表内核；
   - 确立“时间始终作为不可变动力源向前推进”的物理基准：
     - **时序趋势模式（默认开箱即用）**：X 轴绑定时间序列滑动回溯窗口（近 N 分钟），Y 轴绑定数值指标（如航速），横轴随时间匀速向右推进；
     - **自由双轴航迹模式（高级空间映射）**：X 轴与 Y 轴均映射为实体数值属性（如 X=经度，Y=纬度），系统按数据采样的时间戳先后顺序顺次连线，末端最新采样点脉冲高亮，实时描绘船舶航行轨迹线；
   - 图表整体共享统一的 X 轴基准，多曲线各自绑定不同的 Y 轴指标度量与对象占位符，避免同图横坐标双标歧义。

2. **数据类型优先与就地槽位声明（In-situ Slot Placeholder）**：
   - 废除“必须先退到模板根属性建槽位、再进控件选槽位”的割裂路径；
   - 升级检查器为“数据类型优先”模式：先选择数据模式（如 AIS 船舶），在曲线配置中直接提供 `[＋ 新建对象占位符]` 选项与就地重命名输入框；
   - 用户在控件内为占位符命名（如“领航船”、“对比船”）时，系统自动在模板层注册通用槽位（`slots`），全卡片其他控件（如标题、副标题）即刻共享，无需跨视图切换。

3. **工坊预览脱敏与模具认知对齐（Workshop Preview Decoupling）**：
   - 针对工坊制作模板时直接显示具体船名（如“远望1号”）容易产生“模板绑定死数据”的误解，图例与标签强制以占位符别名展示（如“【领航船】 22.7 节”）；
   - 画布显式标注“模具预览中 · 实际船舶在投屏大屏中指派”，在保留波形走势调试价值的同时强化模具抽象性。

4. **全视图模式就地换船触发器（Universal In-situ Retargeting）**：
   - 将卡片右上角 `⇄` 切换船舶悬停入口从原先仅限“显示态”扩展至“编辑态与显示态全量支持”；
   - 编辑态下卡片左上角为拖动抓手（`⠿`）、右上角为换船按钮（`⇄`）、右下角为缩放把手，三者物理空间解耦，大幅缩短调度与调试操作链路。

5. **KPI 指标卡垂直弹性防超边约束（KPI Vertical Bounding Clamping）**：
   - 针对 `.atomic-kpi` 在 `overflow: visible` 状态下中间大数字失控放大至 96px 撑爆 119px 容器并分别超出上边框 3px、下边框 6.3px 的缺陷；
   - 为 `.atomic-kpi` 建立专属字号与间距约束：顶部名称 `clamp(12px, 0.28em, 16px)`、大数字锁定 `clamp(24px, 0.82em, 50px)`、底部时间 `clamp(10px, 0.22em, 12px)`；
   - 确保三行内容在卡片内自适应居中，上下留有 20px+ 安全呼吸间距，杜绝文字骑在边框线上。
