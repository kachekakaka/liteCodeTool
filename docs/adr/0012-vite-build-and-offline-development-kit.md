# 统一 Vite 构建与完整离线开发包

决策已接受（2026-09-07），Vite 构建与离线开发包代码已实施，完整环境验收待完成。本项目必须支持内网离线开发；为减少自制编译器对 Vue 组件写法和依赖引入的限制，统一使用 Vite 开发与构建，以预先准备并带入内网的完整开发包提供 Node、项目依赖及必要的 VS Code 扩展，支持断网启动、前后端调试、格式化与构建，发布包继续支持离线运行。

本决策取代 [ADR 0007](./0007-codebase-flat-integration-and-dual-build.md) 中的双轨构建选择，保留其源码平铺组织决定；不再把缺少 `node_modules` 时仍能编译作为保障目标，依赖更新通过重新准备离线开发包交付。

离线开发包本轮以 Windows x64 为交付和验证目标，须支持迁移目录后的前后端源码断点调试。具体文件组织、命令及验收步骤由正式实施方案和实施后的开发手册维护。
