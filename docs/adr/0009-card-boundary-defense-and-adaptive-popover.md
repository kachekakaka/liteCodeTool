# 0009. 卡片边界防御与自适应排版策略

为解决大屏组件在文本超长、屏幕边缘与复杂层叠下的超边与裁切缺陷，系统确立卡头固定高度弹性截断、背景装饰独立层裁剪、就地浮层智能向上翻转、输入框临时扩展以及表格抽屉弹性自适应全套边界防御机制。

## 决策背景与核心权衡

1. **卡头高度绝对稳定 vs 文本多行撑开**：
   - 拒绝多行自适应折行方案，因为卡头高度撑开会挤压内部核心时序图表与指标网格的有效高度，导致大屏局部比例失调；
   - 采纳单行弹性比例截断（标题上限 60%，副标题上限 35%）配合末尾省略号（`...`）与悬停原生 `title` 提示，保障卡头 45px 稳定高度；
   - 双击就地编辑时，激活的输入框临时自适应扩展（最大可占据 80% 可用宽度），保障编辑输入视野开阔，保存后立即恢复紧凑截断展示。
2. **容器通用裁剪 vs 装饰层物理隔离**：
   - 针对包含 KPI 大尺寸背景装饰图（如雷达、罗盘微标）的卡片，废弃卡片根节点全局 `overflow: hidden`，避免误伤外置缩放把手（`-8px`）和下拉浮层；
   - 新增独立的底层背景裁剪层（`.emblem-layer`）局限背景图溢出，卡片主容器维持 `overflow: visible`。
3. **就地换船浮层边缘翻转**：
   - 当组件卡片位于画布下半区（`y > 600px`）时，就地换船面板自动切换为向上翻折展开（`popover-up`），避免 220px 高的下拉面板超出 1080p 屏幕底边无法点击。
4. **全模式像素级位置稳定（Pixel-Stable）**：
   - 存在对象槽位的卡片，无论在三栏编辑态还是全屏投屏显示态，副标题右侧统一预留 36px 呼吸间距，避免浮现的 `⇄` 切换图标遮挡文字，同时确保模式切换时文字绝对无水平跳跃。
5. **表格与抽屉列表弹性收缩**：
   - 表格控件最后一列（时间戳）由固定 205px 改为弹性范围 `width: clamp(110px, 34%, 180px)`，配合固定表格布局与单行文本省略，适应小尺寸卡片；
   - 全局监控对象抽屉内船名弹性截断，MMSI 与状态徽标固定展示，保持列表纵向高低齐平。
