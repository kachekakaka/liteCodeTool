# 实例私有控件覆盖的稀疏合并机制

在多槽位或复合组件中，用户需要在特定组件实例中修改某个内部控件的数据绑定或展示属性（例如在双船对比卡片中将对象2的副指标由航速改为经度），同时严禁污染源组件模板，也避免对同一模板的其他实例造成副作用。我们决定在组件实例结构中引入“稀疏控件覆盖表（`controlOverrides: { [controlId]: Partial<ControlConfig> }`）”，而在渲染运行时采取源模板控件与实例覆盖项浅合并（Shallow Merge）的解析机制，而非对整套控件树进行深拷贝克隆。这样既保证了持久化 JSON 的轻量纯粹，又维持了底层组件模板后续升级通用样式时对存量实例的向后继承能力。
