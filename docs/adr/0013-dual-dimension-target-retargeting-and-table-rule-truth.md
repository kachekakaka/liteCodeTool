# 0013. 双维度目标重定向、飞行目标度量与表格列规则真源

状态：已接受，2026-09-09 修订。术语见 [CONTEXT.md](../../CONTEXT.md)，交互真源见[原型](../prototypes/prototype.html)，接入格式与升级操作见[快速开发手册](../../快速开发手册.md#飞行目标接入与旧目录升级)。

## 背景

多个传感器可以同时观测同一个飞行目标。此前将业务批号与接入记录 ID 混为一谈，演示数据绕过校验，导致多来源演示能显示而真实接入被拒绝；画布与右侧属性面板也使用了不同的候选列表。仅更新内置模式无法改变用户已有目录，造成旧环境仍看不到高度字段。工坊预览曾误写入模板，并影响不相关槽位。

## 决策

1. **记录身份与业务身份分开**。实体池以模式及接入记录 ID 保存独立数据和历史。模式元数据声明业务目标字段与来源字段，同一业务目标和来源组合只能有一条记录。禁止通过 ID 后缀猜测来源；演示和真实接入共用校验。示例规模由内置数据维护，演示记录数量不作为领域约束。
2. **平台度量统一，接入边界换算**。飞行目标高度和速度统一采用产品要求的工程单位，船舶模式保持已有约定。旧目录的模式、快照、明确关联的阈值和持续输入单位需要一致迁移；无法确定含义的配置停止升级，保留原文件。迁移持有当前数据目录锁，先计算全量改动，再记录原文备份并执行可恢复写入，不清空用户目录。
3. **两处大屏入口共享实例指派**。画布就地面板和右侧属性面板都以业务目标排重，使用同一份目标与来源改绑操作。实例可沿用各曲线配置、显式自动选择一条来源，或严格指定来源。指定来源缺失时保留选择并留白；自动选择不能拼接不同来源历史。旧配置通过版本兼容保留原空值行为。
4. **预览与持久化分开**。工坊预览是按控件和槽位隔离的会话状态，不触发模板脏标记，不写入模板、实例或导出包。大屏实例编辑只能产生私有覆盖；新增、改名或删除共享槽位属于工坊模板设计。切换目标、恢复与撤销不得暗中修改模板。
5. **展示配置保持一个真源**。消息流读取与其他控件一致的有效实例属性；改变保留条数立即裁剪缓冲，切换数据模式清空旧消息。表格列颜色仍由模板声明的列规则驱动，控件不维护隐藏状态颜色映射。

## 取舍

保留轻量实体池和 JSON 文件，不引入新的数据库、事件总线或迁移框架。升级采用一次性版本标记和原文日志，冲突需要先修正可确定的配置再重启。新建共享槽位须到工坊完成，这是避免实例编辑污染所有引用方的边界。规则、具体单位、字段名及启动参数由模式定义和开发手册维护，本 ADR 仅保留决策与理由。
