# 矢量 SVG 图表与 1920×1080 逻辑视口自适应 2K/4K 架构

为了在保证低代码设计态像素级精准排版（基于 1920×1080 标准基准）的同时，满足大屏向 2K (2560×1440) 与 4K (3840×2160) 等超高清物理大屏的无损扩展投屏诉求，我们决定采用“容器逻辑等比缩放引擎（Scale Viewport Container）+ 核心元素矢量 SVG 化（Vector SVG Components）”的混合架构。时序曲线、雷达/波纹动效与卡片切角装饰均采用声明式 SVG（内置 `viewBox` 与自适应比例），外层视口通过 GPU 硬件加速等比缩放。该方案避免了多套媒体查询与 rem 字体抖动问题，使大屏在任意 16:9 高分屏下均能保持工业制图级的极致清晰与零形变。
