# 可配置时间门槛的表格数据陈旧视觉提示

在航运监管大屏中，如果某艘船舶长时间停止上报 AIS 增量，若表格仍以鲜亮高光（如绿色“在航”）呈现其历史最后状态，极易误导调度人员对实时通航态势的判断。为了兼顾业务警示与界面清爽，我们决定在表格控件中引入“可配置时效的双层数据陈旧（Stale）弱化视觉提示”：

1. **表现形式**：采取“整行弱化置灰 + 时间列停更标注”双层展示。整行最新时间戳超时未更新时，该行背景与状态标签适度弱化置灰，直观警示该船舶已停更；同时在“最后上报时间”单元格直接呈现时间置灰或停更状态，清晰醒目，避免对同一行内不同字段采取斑马线式的逐格染色，保持表格工业视觉秩序；
2. **时钟驱动与纯函数下沉**：陈旧计算逻辑下沉至 `src/engine/core.ts` 导出为公开纯函数，由客户端系统定时时钟（每秒递增）统一驱动，确保在完全断流或停止推流时仍能自然进入陈旧态，不依赖新消息触发；
3. **配置契约与边界**：在表格控件属性中统一定义 `staleEnabled: boolean`（默认 true）与 `staleSeconds: number`（默认 120 秒，支持 10~3600 秒）。设为 0 或关闭开关即停用时效监控（用于普通低频字典或静态名册）。明确本决策范围为“整行级停更警示与时间列标注”，不擅自将后端业务状态改写为伪离线，保持业务字段真源纯粹。
