# 数据结构字段表

此文件由 `node tools/export-data-reference.mjs` 根据 [src/types.ts](../../src/types.ts) 和 [内置模式](../../server/defaults.mjs) 生成；修改字段或注释后重新生成，不直接编辑本表。必填列表示 TypeScript 结构要求，HTTP 接入校验、默认值与业务规则见 [数据格式与配置手册](数据格式与配置手册.md)。接口包装结构见 [后端接口契约](后端接口契约.md)。

## Scalar

可通过数据协议传递的标量；null 表示明确上报的空值，字段缺失则表示本次未提供。

```typescript
type Scalar = string | number | boolean | null;
```

## ControlType

平台支持的原子控件类型，分别对应文本、数值、时间、指示灯、表格、曲线、图片和消息流。

```typescript
type ControlType =
  'text' | 'number' | 'time' | 'light' | 'table' | 'line' | 'image' | 'stream';
```

## Field

数据模式中的字段元信息，供绑定选择、格式化与接入校验共用。

| 字段 | 必填 | 类型 | 说明 |
| --- | --- | --- | --- |
| key | 是 | `string` | 字段键名，与数据包 data 中的键一致。 |
| name | 是 | `string` | 界面显示的中文字段名称。 |
| type | 是 | `'string' \| 'number' \| 'enum' \| 'datetime'` | 字段类型；HTTP 接入的 datetime 使用可解析日期字符串，enum 使用字符串选项。 |
| unit | 否 | `string` | 可选显示单位，例如节、度或艘。 |
| precision | 否 | `number` | 数值默认小数位；控件可显式覆盖。 |
| options | 否 | `string[]` | 枚举字段的可选字符串列表。 |

## Schema

一种实体或全局数据的数据模式，声明字段、身份规则及展示名称。

| 字段 | 必填 | 类型 | 说明 |
| --- | --- | --- | --- |
| type | 是 | `string` | 数据模式唯一标识，与 Envelope.type 和槽位 schemaType 对应。 |
| name | 是 | `string` | 数据模式的显示名称。 |
| isEntity | 是 | `boolean` | true 表示存在多个独立实体，false 表示单份全局数据。 |
| idField | 否 | `string` | 实体标识字段键名；全局模式可省略。 |
| targetIdField | 否 | `string` | 业务目标字段；多来源记录可共享同一目标，区别于记录 ID。 |
| sourceField | 否 | `string` | 物理观测来源字段，配合业务目标确定一条观测记录。 |
| fields | 是 | `Field[]` | 该模式允许上报和绑定的字段定义。 |

## Slot

组件模板声明的对象槽位；实例通过槽位 ID 指派具体实体。

| 字段 | 必填 | 类型 | 说明 |
| --- | --- | --- | --- |
| id | 是 | `string` | 模板内唯一槽位 ID，不直接代表实体 ID。 |
| label | 是 | `string` | 面向用户的槽位名称，例如对象1。 |
| schemaType | 是 | `string` | 允许指派的实体数据模式标识。 |

## Geometry

位置与尺寸使用父画布的逻辑像素，独立于浏览器显示缩放。

| 字段 | 必填 | 类型 | 说明 |
| --- | --- | --- | --- |
| x | 是 | `number` | 左上角相对父画布左边缘的横坐标。 |
| y | 是 | `number` | 左上角相对父画布上边缘的纵坐标。 |
| w | 是 | `number` | 逻辑宽度。 |
| h | 是 | `number` | 逻辑高度。 |

## Binding

单个控件字段的完整寻址单元；修改或覆盖时整体替换。

| 字段 | 必填 | 类型 | 说明 |
| --- | --- | --- | --- |
| target | 是 | `'slot' \| 'global'` | slot 从对象槽位取实体数据，global 从全局模式取数据。 |
| slotId | 否 | `string` | target 为 slot 时使用的模板槽位 ID。 |
| schemaType | 否 | `string` | target 为 global 时使用的非实体数据模式标识。 |
| field | 是 | `string` | 需要读取的字段键名。 |

## Series

曲线中的一条数值序列，可来自实体槽位或全局数据。

| 字段 | 必填 | 类型 | 说明 |
| --- | --- | --- | --- |
| target | 否 | `'slot' \| 'global'` | 序列来源；省略时按控件绑定等上下文兼容旧配置。 |
| slotId | 否 | `string` | 实体曲线使用的对象槽位 ID。 |
| schemaType | 否 | `string` | 全局曲线使用的数据模式标识。 |
| field | 是 | `string` | 用于纵轴的数值字段键名。 |
| color | 否 | `string` | 曲线颜色；省略时由图表采用默认配色。 |
| label | 否 | `string` | 可选曲线显示名称。 |
| yAxis | 否 | `'left' \| 'right'` | 曲线归属的 Y 轴：left 为左轴（默认），right 为右轴。 |
| filterSource | 否 | `string` | 可选数据源过滤，用于在多源探测（如雷达/遥测）时限定曲线来源。 |

## TableColumnRule

表格列级状态颜色规则集合。

| 字段 | 必填 | 类型 | 说明 |
| --- | --- | --- | --- |
| field | 是 | `string` | 目标列的字段键名。 |
| rules | 是 | `{ value: Scalar; color: string; }[]` | 该列匹配的有序颜色规则。 |

## ControlProps

各类控件共用的属性集合；属性均可省略，具体默认值由对应控件和校验逻辑决定。

| 字段 | 必填 | 类型 | 说明 |
| --- | --- | --- | --- |
| sourceMode | 否 | `'static' \| 'dynamic'` | static 使用固定内容，dynamic 读取绑定字段；省略时兼容旧绑定配置。 |
| staticValue | 否 | `Scalar` | 固定内容原始值；null 表示明确空值。 |
| label | 否 | `string` | 控件标签文案。 |
| labelMode | 否 | `'auto' \| 'custom'` | auto 继承字段名称，custom 使用 label。 |
| unit | 否 | `string` | 控件自定义单位文本。 |
| unitMode | 否 | `'auto' \| 'custom'` | auto 继承字段单位，custom 使用 unit。 |
| precision | 否 | `number \| null` | 指定显示小数位；null 或省略表示使用字段默认精度或原值。 |
| lookbackUnit | 否 | `'second' \| 'minute'` | 曲线历史窗口长度单位：minute 表示分钟（默认），second 表示秒。 |
| lookbackSeconds | 否 | `number` | 曲线历史窗口长度，单位秒，允许 10～600。 |
| lookbackMinutes | 否 | `number` | 曲线历史窗口长度，单位分钟，允许 1～60。 |
| tableColumnRules | 否 | `TableColumnRule[]` | 表格列级状态颜色规则列表。 |
| streamMaxItems | 否 | `number` | 消息流最大留存条数，默认 50。 |
| streamAutoScroll | 否 | `boolean` | 消息流是否自动滚动吸底，默认 true。 |
| gapSeconds | 否 | `number` | 时序曲线相邻点允许连接的最大时间间隔，单位秒。 |
| staleSeconds | 否 | `number` | 数据过期阈值，单位秒；非正数关闭判定。 |
| staleEnabled | 否 | `boolean` | 表格是否启用整行过期显示，省略时由表格默认策略决定。 |
| series | 否 | `Series[]` | 图表数值序列集合，最多 8 条；覆盖时整体替换。 |
| columns | 否 | `string[]` | 表格展示列的字段键名，数组顺序即列顺序。 |
| schemaType | 否 | `string` | 表格所使用的实体数据模式标识。 |
| filterField | 否 | `string` | 表格等值过滤的字段键名；省略时不过滤。 |
| filterValue | 否 | `Scalar` | 与过滤字段比较的标量值。 |
| pageSize | 否 | `number` | 表格每页行数，允许 1～20。 |
| colorRules | 否 | `{ value: Scalar; color: string; }[]` | 指示灯按值匹配颜色的有序规则，最多 30 条。 |
| imageType | 否 | `'radar' \| 'sonar' \| 'image'` | radar 和 sonar 使用内置效果，image 使用图片地址。 |
| imageUrl | 否 | `string` | 图片或 KPI 图标地址；内嵌图片使用允许格式的 Base64 Data URL。 |
| alt | 否 | `string` | 图片的替代文本。 |
| clock | 否 | `boolean` | 是否将当前时钟作为静态控件值。 |
| variant | 否 | `'standard' \| 'kpi'` | 数值控件样式：standard 为普通数值，kpi 为指标卡。 |
| iconType | 否 | `'vessel' \| 'cargo' \| 'fishing' \| 'alert' \| 'none'` | KPI 内置图标类型，none 表示不显示图标。 |
| autoPageSeconds | 否 | `number` | 表格自动翻页间隔，单位秒；非正数关闭自动翻页。 |
| xAxisMode | 否 | `'time' \| 'field'` | time 以时间为横轴，field 将 X/Y 数值字段组成航迹。 |
| xAxisField | 否 | `string` | 字段横轴使用的数值字段键名。 |
| xAxisSlotId | 否 | `string` | 字段横轴指定的对象槽位 ID；省略时由图表上下文回退。 |
| xAxisSchemaType | 否 | `string` | 图表选择的数据模式上下文，用于字段与序列配置。 |
| workshopPreviewTarget | 否 | `string` | 仅兼容读取旧配置；载入、保存与导出时剥离，新预览存于工坊会话状态。 |

## Control

模板内的原子控件定义，实例可通过 Override 私有化其样式、属性和绑定。

| 字段 | 必填 | 类型 | 说明 |
| --- | --- | --- | --- |
| id | 是 | `string` | 模板内唯一控件 ID，用作覆盖映射键。 |
| type | 是 | `ControlType` | 控件类型。 |
| style | 是 | `Geometry & { fontSize?: number; color?: string; }` | 相对模板画布的几何信息与可选字号、颜色。 |
| props | 是 | `ControlProps` | 控件专属属性集合。 |
| binding | 否 | `Binding \| null` | 动态字段绑定；null 或省略表示没有显式字段绑定。 |

## Override

实例对单个控件的稀疏覆盖；未出现的字段继续继承模板。

| 字段 | 必填 | 类型 | 说明 |
| --- | --- | --- | --- |
| style | 否 | `Partial<Control['style']>` | 仅覆盖提供的几何或样式字段。 |
| props | 否 | `Partial<ControlProps>` | 仅覆盖提供的控件属性，数组值整体替换。 |
| binding | 否 | `Binding \| null` | 提供时整体替换绑定；null 清除绑定，省略则保持继承。 |

## ComponentTemplate

可重复使用的组件模板，定义布局、对象槽位、控件与默认标题配置。

| 字段 | 必填 | 类型 | 说明 |
| --- | --- | --- | --- |
| id | 是 | `string` | 模板资源唯一标识。 |
| name | 是 | `string` | 模板名称，也是实例没有私有标题时的默认标题。 |
| category | 是 | `string` | 资产库分类名称。 |
| layout | 是 | `{ width: number; height: number; }` | 模板画布逻辑尺寸，单位像素。 |
| slots | 是 | `Slot[]` | 模板声明的对象槽位列表。 |
| controls | 是 | `Control[]` | 模板内原子控件列表。 |
| showHeader | 否 | `boolean` | 是否显示标题栏；省略时由组件默认规则决定。 |
| decoration | 否 | `'card' \| 'banner'` | 外观类型，card 为卡片，banner 为横幅。 |
| subTitle | 否 | `string` | 模板副标题；空字符串显式隐藏，省略时按槽位生成默认文案。 |

## ComponentInstance

大屏中的模板实例，保存摆放位置、对象指派和不影响其他实例的私有配置。

| 字段 | 必填 | 类型 | 说明 |
| --- | --- | --- | --- |
| instanceId | 是 | `string` | 大屏内唯一实例标识。 |
| templateId | 是 | `string` | 引用的组件模板资源 ID。 |
| title | 否 | `string` | 实例私有标题；省略时使用模板名称。 |
| subTitle | 否 | `string` | 实例副标题覆盖；空字符串显式隐藏，省略时继承模板。 |
| position | 是 | `Geometry & { zIndex?: number; }` | 相对大屏的逻辑几何信息及可选层级。 |
| showHeader | 否 | `boolean` | 实例标题栏开关；省略时继承模板。 |
| slotBindings | 是 | `Record<string, string>` | 模板槽位 ID 到业务目标 ID（批号或 MMSI）的映射；没有对应键表示未指派。 |
| slotSourceBindings | 否 | `Record<string, string>` | 槽位 ID 到来源的映射；版本 2 中缺失键表示继承曲线来源，空字符串表示自动选择单条记录，来源名称表示严格指定。 |
| controlOverrides | 是 | `Record<string, Override>` | 模板控件 ID 到私有覆盖项的映射。 |

## ScreenConfig

可保存、导入导出的大屏配置；运行时实体数据和编辑历史不属于该配置。

| 字段 | 必填 | 类型 | 说明 |
| --- | --- | --- | --- |

| id | 是 | `string` | 大屏资源唯一标识。 |
| name | 是 | `string` | 大屏显示名称。 |
| resolution | 是 | `{ width: number; height: number; }` | 大屏逻辑分辨率，单位像素。 |
| background | 是 | `string` | 六位十六进制背景色，例如 #030B17。 |
| components | 是 | `ComponentInstance[]` | 大屏上的组件实例列表。 |

## Envelope

实体或全局数据包；同一结构也用于底账，底账可携带逐字段源时间。

| 字段 | 必填 | 类型 | 说明 |
| --- | --- | --- | --- |
| type | 是 | `string` | 数据模式标识，与 Schema.type 对应。 |
| id | 否 | `string` | 实体模式必须提供实体 ID；全局模式省略。 |
| timestamp | 是 | `number` | 源数据时间戳，单位毫秒；不是客户端接收时间。 |
| data | 是 | `Record<string, Scalar>` | 本次提供的字段子集；null 覆盖为空，未出现的字段保留旧值。 |
| fieldTimestamps | 否 | `Record<string, number>` | 底账中的逐字段源时间戳，单位毫秒；由服务端生成，外部增量不能伪造。 |

## Point

单个字段的历史样本，null 用于保留空值并中断曲线连接。

| 字段 | 必填 | 类型 | 说明 |
| --- | --- | --- | --- |
| timestamp | 是 | `number` | 样本的源时间戳，单位毫秒。 |
| value | 是 | `number \| null` | 有限数值或明确空值，不用 0 替代缺失。 |

## EntityRecord

实体池中的一条记录，分别保存最新字段值、逐字段源时间和数值历史。

| 字段 | 必填 | 类型 | 说明 |
| --- | --- | --- | --- |
| data | 是 | `Record<string, Scalar>` | 按字段键保存的最新标量值。 |
| timestamps | 是 | `Record<string, number>` | 按字段键保存的最新源时间戳，单位毫秒。 |
| history | 是 | `Record<string, Point[]>` | 按字段键保存的历史点集；初始底账不生成历史。 |

## ResolvedValue

控件显示层读取的解析结果，同时保留原始值和格式化后的文案。

| 字段 | 必填 | 类型 | 说明 |
| --- | --- | --- | --- |
| value | 是 | `string` | 格式化显示文本，缺失或无效值通常为 --。 |
| raw | 是 | `Scalar \| undefined` | 未经格式化的标量；undefined 表示字段缺失。 |
| label | 是 | `string` | 最终采用的标签名称。 |
| unit | 是 | `string` | 最终采用的单位文本。 |
| timestamp | 是 | `number \| null` | 动态字段的源时间戳，单位毫秒；静态内容或无源时间时为 null。 |
| empty | 是 | `boolean` | 是否属于缺失、明确空值或无效数值。 |
| stale | 是 | `boolean` | 是否已超过当前控件的时效阈值。 |
