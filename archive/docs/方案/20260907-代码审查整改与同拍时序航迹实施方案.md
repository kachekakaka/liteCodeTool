# 20260907-代码审查整改与同拍时序航迹实施方案

## 问题陈述 (Problem Statement)

在近期自由双轴映射与防超边功能实施完毕并通过初步审查后，通过全量代码审查（Code Review）及架构深度研讨，暴露出一批亟待闭环的架构规范、性能瓶颈、契约消费与测试缺陷：

1. **核心算法内联与 $O(N^2)$ 计算瓶颈**：
   - 自由双轴空间航迹对齐逻辑直接写在展示层组件 `LineChart.vue` 的 `computed` 计算属性中，违背《快速开发手册》关于“复杂数据解析与时效算法必须作为纯函数放在 `core.ts`”的架构铁律；
   - 现存算法使用 5 秒模糊容差进行双重嵌套循环比对，当回溯点数为 $N$ 时，每次推流渲染触发 $O(N^2)$ 次比较（如 500 点产生 250,000 次比对），严重浪费前端算力，且越界承担了本该由源端/后端保证的数据对齐职责。

2. **单测虚假绿灯（False Green）**：
   - `tests/core.test.ts` 中的模板 fixture 仅包含 `number` 控件，导致 `tpl.controls.find(c => c.type === 'line')` 永远返回 `undefined`；
   - 内部对 `xAxisMode` 与 `xAxisField` 合法性及非法拒绝的断言全部被 `if (lineCtrl)` 静默跳过，测试虽显示通过但实际未执行任何有效断言。

3. **文档与代码类型真源脱节**：
   - 代码真源 `src/types.ts` 采用符合极简低代码架构的扁平单体接口 `Control + ControlProps`；
   - 《快速开发手册.md》却展示了 Tagged Union（`ValueControl | ProgressControl`）联合类型教程代码，导致文档与代码真源不一致。

4. **契约未消费与样式文案小缺陷**：
   - `src/types.ts` 已定义 `xAxisSlotId` 契约，但在属性面板与图表组件中未读取消费，多曲线不同对象时 X 轴无法按槽位映射；
   - 换船浮层向上翻折偏移符号误写为 `bottom: calc(100% - 8px)`，导致浮层向下侵入卡片内部 8px 遮挡边框；
   - 工坊图例模具预览提示文案缺失后半句说明；
   - 卡片双击就地编辑标题时直接跨组件通过 `document.querySelector` 查询物理 DOM 聚焦，存在代码异味。

---

## 解决方案 (Solution)

1. **同拍时序航迹纯函数下沉与线性对齐（$O(N)$ 复杂度）**：
   - 确立源端一致性原则：船舶经度与纬度在 AIS 报文中同帧打包下发，时间戳天然一致；异构脱节由后端采集服务保障；
   - 在 `src/engine/core.ts` 抽象纯函数 `alignTrajectoryPoints`，通过时间戳哈希映射以 $O(N)$ 线性时间极速对齐轨迹点对，彻底消除嵌套循环；
   - 组件 `LineChart.vue` 纯粹只负责调用该纯函数并绘制 SVG 轨迹与发光动效。

2. **修复单测虚假绿灯与覆盖真实航迹对齐**：
   - 在 `tests/core.test.ts` 中构造标准折线图 fixture，恢复 `validateTemplate` 的非法模式拦截断言；
   - 新增针对 `alignTrajectoryPoints` 的多组独立纯函数单测（覆盖同拍精确对齐、单字段丢点断流、时间戳乱序自适应重排等）。

3. **开发手册与代码真源对齐**：
   - 修正《快速开发手册.md》中新增控件教程的示例代码，使其完全契合 `src/types.ts` 的扁平单体契约。

4. **契约消费与交互样式规范闭环**：
   - `Inspector.vue` 在自由双轴模式下提供“X 轴对象槽位”选择器并存入 `xAxisSlotId`，`LineChart.vue` 优先从该槽位提取 X 轴数值序列（缺省回退首条曲线槽位）；
   - `src/styles.css` 修正 `bottom: calc(100% + 8px)`，恢复顶部安全呼吸间隙；
   - `LineChart.vue` 工坊提示补齐为：“模具预览中 · 实际船舶在投屏大屏中指派”；
   - 标题与副标题就地编辑聚焦逻辑改用标准 Vue 声明式 `ref` 绑定。

## 用户故事 (User Stories)

1. 作为一名大屏设计者与运维调度员，我希望在大屏展示多点位、长时间跨度船舶航迹时，前端渲染性能保持微秒级丝滑流畅，以便于长时间监控不掉帧、不卡死浏览器。
2. 作为一名平台架构师与核心开发者，我希望核心的数据解析、时间窗口截取与轨迹提取算法始终以纯函数形态下沉并接受严苛单测保护，以便于未来重构或升级时杜绝隐蔽 Bug。
3. 作为一名质量保障人员，我希望测试套件中所有断言均得到真实执行，绝不存在因数据夹具缺陷导致的静默跳过或虚假绿灯，以便于每次测试全绿都具备不可动摇的置信度。
4. 作为一名新加入项目的开发人员，我希望阅读《快速开发手册》时获取的类型契约与源码真源完全一致，以便于快速准确地开发新控件，无需反复比对文档与源码。

## 实现决策 (Implementation Decisions)

### 1. 纯计算层：同拍时序航迹提取算法 (`src/engine/core.ts`)
- 新增纯函数导出：
  ```typescript
  export interface TrajectoryPoint {
    xVal: number;
    yVal: number;
    timestamp: number;
  }

  export function alignTrajectoryPoints(
    xPoints: Array<{ timestamp: number; value: number | null }>,
    yPoints: Array<{ timestamp: number; value: number | null }>
  ): TrajectoryPoint[]
  ```
- **算法实现**：
  - 构造 `xMap = new Map<number, number>()`，将 `xPoints` 中 `value !== null` 的项按时间戳存入哈希表；
  - 遍历 `yPoints`，当 `yPt.value !== null` 且 `xMap.has(yPt.timestamp)` 时，直接取出对应的 `xVal` 合成 `{ xVal, yVal, timestamp }`；
  - 整体耗时仅为 $O(X + Y)$ 线性时间，内存消耗极低。

### 2. 展示层解耦与文案补齐 (`src/components/LineChart.vue`)
- 移除组件内部内联的 5 秒循环查找逻辑，直接调用 `alignTrajectoryPoints`；
- 支持从 `props.control.props.xAxisSlotId` 指定的槽位获取 X 轴数据记录（缺省回退首条曲线所在槽位对应的记录）；
- 工坊模具预览提示文案补全：
  ```vue
  <span class="workshop-chart-hint">模具预览中 · 实际船舶在投屏大屏中指派</span>
  ```

### 3. 属性检查器槽位消费 (`src/components/Inspector.vue`)
- 当折线图的 `xAxisMode === 'field'` 时，在横轴字段选择器下方展示“X 轴基准对象”下拉选框；
- 选项取当前模板声明的槽位列表（`template.slots`），值绑定到 `control.props.xAxisSlotId`；若未选择，默认标注为“跟随首条曲线”。

### 4. 样式修正与 Vue 规范聚焦 (`src/styles.css`, `src/components/InstanceCard.vue`)
- `src/styles.css`:
  ```css
  .insitu-popover.popover-up {
    top: auto !important;
    bottom: calc(100% + 8px) !important;
    box-shadow: 0 -12px 36px rgba(0, 0, 0, 0.75) !important;
  }
  ```
- `src/components/InstanceCard.vue`:
  - 声明 `titleInputRef = ref<HTMLInputElement | null>(null)` 与 `subTitleInputRef = ref<HTMLInputElement | null>(null)`；
  - 在 `nextTick` 中直接调用 `titleInputRef.value?.focus()`，彻底废除 `document.querySelector` 原生全局查找。

### 5. 文档修正 (`快速开发手册.md`)
- 修正第四节“如何增加一个新的原子控件”，将 `export type Control = ...` 替换为正确的扁平接口规范：
  ```typescript
  // 在 ControlType 中增加类型标识
  export type ControlType = 'number' | 'text' | 'time' | 'light' | 'table' | 'line' | 'image' | 'progress';

  // 在 ControlProps 中扩充私有配置项
  export interface ControlProps {
    // ...既有属性
    min?: number;
    max?: number;
    color?: string;
  }
  ```
