## 问题陈述 (Problem Statement)

在导弹、火箭及复杂海空态势监控的实际业务场景中，当前低代码大屏存在以下关键限制与体验断层：

1. **曲线量纲冲突与经纬度时序缺失**：当前折线图仅提供单一 Y 轴。当多条曲线数值差异极大（如飞行高度 0~10000 米与飞行速度 0~800 m/s，或经度 120° 与纬度 30°）时，单轴缩放会导致小数值曲线被压缩为一条毫无波动细节的平线，且触发“单位不兼容”告警。此外，经纬度此前被固定为空间二维轨迹（X=经度, Y=纬度），无法按时间推移同时观察经度与纬度各自随时间的变化曲线。
2. **时间轴粒度粗且无法适配短周期目标**：导弹等高速目标飞行全程仅 1~2 分钟甚至几十秒，而当前滑动时间窗口最小只能设为 1 分钟且按整数分钟跳进，导致短周期目标的数据被紧挤在图表最右侧边缘，缺乏秒级（`HH:mm:ss`）自适应刻度支持。
3. **缺少空天飞行实体模型与数据源筛选**：系统当前内置的数据模式仅覆盖 AIS 船舶与港口统计，缺失高度单位及飞行器/弹药（`projectile`）专用数据模式。多雷达或遥测多源上报同名目标时，无法在图表中指定数据来源。
4. **状态颜色规则仅支持全等且表格未开放配置**：指示灯组件的颜色规则只支持严格文本全等匹配，操作人员无法为航速、高度等数值型字段设定阈值区间（如 `> 30` 或 `10..20`）；同时表格控件的颜色直接硬编码在展示层中，属性面板未开放列级状态规则配置。
5. **表格关键参数缺乏快速走势探查能力**：监控人员在表格中巡检多目标数值参数时，无法就地快速查看其历史波动走势，必须跳出或重配独立图表，操作链路割裂。
6. **动态文本追加日志流（Message Stream）缺失**：原系统中存在“来一条追加一条平滑向上滚动”的事件与报文日志流，而当前平台仅有单值文本控件，无法承载系统推流消息的连续展示。

## 解决方案 (Solution)

1. **解耦双 Y 轴时序图表引擎**：重构时序折线图内核，每条曲线在配置中可自由指派挂载于 `左轴 [Y1]` 或 `右轴 [Y2]`。左右轴各自拥有独立的极值范围、自适应步长与单位标注；未配置右轴时自适应隐藏，维持极简单轴外观。
2. **亚分钟与秒级自适应滑动时间轴**：回溯窗口扩展支持“秒（10s~600s）”与“分钟（1m~60m）”双模式。当窗口 $\le 180$ 秒时刻度自动精确到 `HH:mm:ss`；维持标准滑动窗口物理模型，最新点固定在右侧，匀速向左推移。
3. **标准化飞行目标 Schema 与多源筛选**：新建 `projectile` 实体模式，内置批号、高度（米）、速度（m/s）、经纬度、航向及数据来源（`source`）字段；曲线数据源支持按实体槽位选择并可附加传感器来源过滤。
4. **轻量通用数值区间规则引擎**：在纯函数计算层统一实现表达式解析器，支持 `> X`、`>= X`、`< X`、`<= X`、`min..max` 与全等文本匹配；指示灯属性面板增加语法提示；表格属性面板开放“列状态颜色”配置，命中的数值文字以告警色高亮。
5. **单元格趋势微图浮层 (Sparkline Popover)**：在表格数值单元格引入原地轻量微图交互。点击带有历史时序缓冲的数值，就地弹出紧凑气泡，展示近 2 分钟走势与极值，再次点击或失焦自动收起。
6. **新原子控件：滚动消息流 (Message Stream)**：新增 `stream` 控件类型，订阅全局或实体事件日志流，采用自底向上淡入追加、平滑上滚与悬停暂停机制，可配置最大缓冲条数。

## 用户故事 (User Stories)

1. 作为一名态势监控指挥员，我想要在同一张折线图上同时查看飞行目标的“高度”与“速度”曲线，以便于我无需切换页面即可精准分析俯冲、爬升与加速度阶段。
2. 作为一名测控工程师，我想要在折线图上分别将经度和纬度作为两条曲线随时间绘制（左轴经度、右轴纬度），以便于我沿时间基准核验目标的轨迹变化与授时同步。
3. 作为一名指挥大屏设计者，我想要只配置左轴单曲线时右轴不占位、配置右轴曲线时右轴自动出现，以便于我的大屏在各种简单与复杂图表场景下都保持整洁美观。
4. 作为一名导弹试验观察员，我想要将回溯时间窗口设置为 30 秒或 60 秒，并看到精确到秒（`HH:mm:ss`）的横轴刻度，以便于清晰观测 1~2 分钟内高速飞行弹药的全部动态细节。
5. 作为一名大屏搭建人员，我想要在添加飞行目标曲线时选择指定的数据来源（如“雷达1”或“遥测真值”），以便于在多源传感器同时探测同一目标时进行真值与测量值的同屏对比。
6. 作为一名运维监控人员，我想要在指示灯和表格中直接输入 `> 80` 或 `10..20` 来定义颜色规则，以便于我能轻松根据数值高低判断设备与指标是否处于超温、超速或告警状态。
7. 作为一名大屏操作员，我想要在巡检数据表格时点击某个数值单元格直接弹出近 2 分钟的历史微型趋势走势，以便于我原地快速确认该参数是否处于异常突增状态而无需打扰大屏整体布局。
8. 作为一名值班监控调度员，我想要在页面上看到一个自动向上滚动的系统报文与告警流，新消息来一条追加一条，鼠标悬停时暂停滚动，以便于我实时跟踪现场发出的突发事件与操作指令。

### 2. 纯计算引擎与算法下沉 (src/engine/core.ts)

严格遵循《快速开发手册》规范，所有无状态计算下沉至 `src/engine/core.ts`：

- **区间与阈值规则解析器 `evaluateColorRule(value: Scalar, rules: { value: Scalar; color: string }[]): string | null`**：
  - 支持单侧比较：`> X`、`>= X`、`< X`、`<= X`；
  - 支持闭区间：`min..max`（如 `10..20`）；
  - 支持普通标量与文本全等：`value === rule.value`；
  - 按数组从上到下执行短路匹配，首个命中规则返回对应的 `color`，未命中或空值返回 `null`。
- **自适应时间轴刻度生成器 `generateTimeTicks(now: number, durationMs: number, count: number): { time: number; label: string }[]`**：
  - 当 `durationMs <= 180,000`（3 分钟内），格式化为 `HH:mm:ss`；
  - 当 `durationMs > 180,000`，格式化为 `HH:mm`。
- **双 Y 轴极值与坐标映射 `calculateExtents(points: Point[], padRatio = 0.08)`**：
  - 分离计算左轴集合与右轴集合的极值范围；若某轴无数据或单值，给予合理的保底区间；
  - 提供左右轴独立的 $Y$ 坐标映射函数。

### 4. 前端组件与交互升级

- **折线图组件 (`src/components/LineChart.vue`)**：
  - 绘图区两端支持双 Y 轴刻度：左轴基线 `x=58`，右轴基线 `x=1142`（仅在有右轴曲线时渲染右轴线、右侧刻度及右轴单位文本）；
  - 悬停浮层显示时，各项数据标注清晰指示 `[左轴]` 或 `[右轴]`；
  - 废除跨单位强行报错阻断，双轴天然包容不同单位。
- **折线图检查器 (`src/components/inspector/LineProperties.vue`)**：
  - 回溯窗口表单增加单位切换（秒 / 分钟）；
  - 曲线列表项中，为每条曲线增加 `[轴向: 左轴/右轴]` 切换按钮，以及 `[数据来源过滤]` 可选下拉框。
- **指示灯检查器 (`src/components/inspector/LightProperties.vue`)**：
  - 规则输入框旁增加占位提示与规则编写指南小贴士（例如“支持 >30、10..20、正常”）。
- **表格组件与检查器 (`TableControl.vue` & `TableProperties.vue`)**：
  - 检查器中新增“列状态颜色”面板：选择某一列，添加多条区间规则；
  - 表格渲染时调用 `evaluateColorRule` 动态为单元格文字加粗并染色；
  - 数值单元格支持点击触发轻量趋势浮层 `SparklinePopover`（内置微型 SVG 折线，展示近 2 分钟历史，展示最新/最大/最小统计值，点击空白处自动关闭）。
- **消息流控件 (`src/components/controls/StreamControl.vue`)**：
  - 新建专用原子控件：列表底部实时追加新消息，CSS 平滑上移，滚动条默认吸底；
  - 鼠标悬停进入控件范围时自动暂停滚动，移出后恢复；
  - 消息级别（`info/warn/error`）对应青色/黄色/红色圆点状态标牌。
- **资产库与设计器注册 (`AssetLibrary.vue` & `WorkspaceToolbar.vue`)**：

## 测试决策 (Testing Decisions)

### 1. 测试标准与原则
- 坚决落实极简实用主义，坚决不引入 UI 自动化、E2E 或重型浏览器测试体系；
- 仅针对底层核心算法、解析器与纯函数编写轻量、快速、确定性的纯 TypeScript 单元测试。

### 2. 核心测试接缝 (Seams) 与覆盖清单
所有新增关键逻辑收敛至单测试接缝：`tests/core.test.ts`：

- **接缝 1：区间规则解析算法 (`evaluateColorRule`)**
  - 单侧大于/小于/大于等于/小于等于（如 `> 30` 在 35 时命中，25 时不命中）；
  - 闭区间范围匹配（如 `10..20` 在 10、15、20 时命中，9 和 21 时不命中）；
  - 字符串/枚举全等匹配（如 `告警` 命中，未匹配项回退 `null`）；
  - 异常输入（非数字字符串匹配数值比较、null/undefined 输入安全防御）。
- **接缝 2：双 Y 轴极值与自适应映射算法**
  - 左轴右轴曲线数据分离与各自上下限独立计算；
  - 单值或全 0 边界条件下的保护性值域跨度（避免除零导致 NaN 坐标）。
- **接缝 3：自适应时间轴刻度生成器**
  - 短周期（如 30 秒、60 秒）时刻度格式严格匹配 `HH:mm:ss`；
  - 长周期（如 10 分钟）时格式严格匹配 `HH:mm`。

复用 `tests/core.test.ts` 中既有的 `alignTrajectoryPoints`、`inWindow` 和 `isRecordStale` 单元测试规范，直接在 `npm test` 中运行验证。
