# 轻量化低代码大屏平台实施方案 (AIS 船舶监控典型应用 · 科技蓝纯图表修订版)

版本：V2.0 · 修订日期：2026-09-06 · 完成日期：2026-09-07

> **验证结论**：全量实施完成并验证通过，平铺合库与功能差距已在后续专项方案中闭环归档。

## 问题陈述 (Problem Statement)

在船舶监控（AIS）等指挥大屏业务中，现场大屏界面种类繁多、指标要求多变。传统硬编码开发模式周期长、修改成本高，且旧版原型存在以下痛点：
1. **视觉表现偏向普通深色工具后台**：卡片层级相近、缺少视觉呼吸感与专业科技质感，不能满足调度指挥中心严苛的视觉冲击力需求；
2. **中心硬编码与地图依赖**：传统大屏过度依赖重型 GIS 海图或三维地球，资源消耗极大，且限制了数据排版的自由度；
3. **动静绑定与多槽位割裂**：大屏在投屏监控（显示态）下无法应对现场突发调度（如突然进港一艘重点新船，无法在运行态快速将卡片切换绑定至该船）；同时单个卡片难以优雅支持多槽位（如同时并列展示对象1与对象2名字），且实例级微调字段容易污染源组件模板；
4. **数据驱动卡顿与缺字段失真**：后端通过 WebSocket 高频推送海量船舶增量数据，传统遍历组件树刷新容易造成界面顿挫；同时若单纯依赖增量推送，用户在界面调整指标（如改看经度）或刚打开页面时容易因未上报而呈现空白，甚至部分原型出现用伪造时序曲线冒充生产数据的失真隐患；
5. **高分大屏适应性不足**：固定分辨率排版在现场 2K (2560×1440) 或 4K (3840×2160) 高清大屏上容易产生拉伸模糊或黑边溢出。

## 解决方案 (Solution)

构建一套**科技蓝风格、纯图表布局、矢量化 SVG 驱动、轻量解耦的低代码大屏平台**：
1. **纯图表首版 1920×1080 标准栅格体系**：
   - 彻底摒弃地图与三维地球，不堆砌未经数据源验证的环图与虚构健康度；
   - 采用“总览（4 张独立科技蓝指标卡）→ 趋势与重点监控（左 2/3 多船航速时序主曲线 + 右 1/3 单船监控）→ 对比与明细（左 1/3 双船对比 + 右 2/3 商船动态表格）”的标准层次排版。
2. **科技蓝工业设计系统 (Industrial Tech Blue Design Tokens)**：
   - 采用分层深海军蓝背景（`#030B17` / `#071B35` / `#071426` / `#081B30` / `#0C2540`）；
   - 卡片采用细蓝边框（`#17486B`）、轻切角与局部亮角装饰，配合微弱发光光轨（`#22D3EE`）；
   - 大指标采用等宽数字体系（`tabular-nums`，44~60px），业务语义优先（告警专用 `#FF667A`，正常采用 `#25D8AE`）。
3. **矢量 SVG 体系与 2K/4K 视口自适应**：
   - 时序曲线、雷达扫描、装饰切角与指示图表统一采用声明式 SVG（内置 `viewBox` 与自适应比例）；
   - 采用逻辑等比自适应缩放视口（`Vector Adaptive Viewport`），在 1080P、2K、4K 超高清大屏下自动铺满视口，边缘极致锐利、零锯齿、零滚动条。
4. **七大核心原子控件与双模数据源**：
   - 原子控件包含：图片/动图框（`ImageBox`）、文本框（`TextBox`）、数值框（`NumberBox`）、时间框（`TimeBox`）、指示灯（`StatusLight`）、表格（`TableBox`）、曲线（`LineChart`）；
   - 文本框与各类输入框支持【静态固定录入】与【动态数据绑定】单选显式互斥（`sourceMode`），静态标题绝不被推流冲刷；
   - 画布直接拖入原子控件自动包裹为“单控件组件实例”。
5. **无头纯净模式与双层切船调度**：
   - 卡头可一键隐藏进入“无头纯净模式”；
   - **全局层**：右上角常驻“🔍 监控对象”侧滑抽屉，统览所有卡片槽位，支持船名/MMSI 搜索换船与默认配置固化；
   - **局部层**：无头卡片支持“鼠标停留悬停 400ms”或“触控长按 500ms”就地呼出切船气泡，防误触且调度便捷。
6. **时序曲线滑动回溯时间窗口 (Sliding Lookback Window)**：
   - 控件支持自主配置时间跨度（默认 20 分钟，可选 15/30/60 分钟）；
   - 窗口内真实绘制，未蓄满区间如实留白向右延伸，超出窗口旧点平滑滑出，绝不伪造历史。
7. **闭环可靠的数据总线与轻量落地**：
   - HTTP 查初始底账 + WebSocket 增量更新入前端响应式实体池（`Entity Store`），空值优雅降级为 `--`；
   - Vue 3 + Vite + TypeScript + Node.js，纯 JSON 存储于外部数据目录（`../liteCodeTool_datas/`），零数据库依赖。

## 用户故事 (User Stories)

### 一、组件制作与资产沉淀 (Component Authoring)
1. 作为一名组件设计者，我想要在组件工坊中将七大原子控件（图片/动图、文本、数值、时间、指示灯、表格、曲线）灵活装配，以便于沉淀标准化业务组件。
2. 作为一名组件设计者，我想要在组件中声明多个抽象“对象槽位”（如对象1、对象2）并将不同控件独立映射到不同槽位，以便于支持双船对比等复杂场景。
3. 作为一名组件设计者，我想要为文本框配置【静态固定录入】模式，以便于直接打字输入大屏大标题或固定警示标牌，且不被推流冲刷。
4. 作为一名组件设计者，我想要为图片控件配置纯 CSS/SVG 科技动效（动态雷达扫描、声纳波纹），以便于在无实时推流数据时大屏也能展现高端科技质感。

### 二、大屏设计与编排 (Screen Canvas Editing)
5. 作为一名大屏制作人员，我想要在 1920×1080 标准栅格画布上自由拖拽组件实例并调整层级，以便于排布出工整大气的科技蓝大屏。
6. 作为一名大屏制作人员，我想要直接把原子控件（如单个图片框或文本框）拖入画布，系统自动将其包装为组件实例，以便于随手增补标牌而无需跨工作台新建模板。
7. 作为一名大屏制作人员，我想要在特定实例中私有修改对象2绑定的字段（如将航速换为经度），以便于微调看板且绝不污染原始组件模板（稀疏覆盖）。
8. 作为一名大屏制作人员，我想要为时序曲线配置【滑动回溯时间窗口】（如 20 分钟），以便于掌控数据有效周期。

### 三、现场监控与动态调度 (Runtime Monitoring & Viewing)
9. 作为一名大屏监控值班员，我想要进入 100% 满屏无死角的科技蓝显示态，顶栏和侧栏自动隐退，以便于大屏沉浸投屏并锁定排版防误触。
10. 作为一名大屏监控值班员，我希望大屏投影到 2K 或 4K 大屏时能够等比自适应矢量缩放，以便于图表和文字始终极致锐利、无锯齿和无黑边。
11. 作为一名大屏监控值班员，在开启无头纯净模式时，我想要通过右上角“监控对象”抽屉搜索船名或 MMSI 快速切船，并提示未保存变更，以便于掌握全港调度视角。
12. 作为一名大屏监控值班员，在显示态下我想要通过鼠标在卡片悬停 400ms 或在触屏上长按 500ms 快速呼出就地切船小气泡，以便于秒级切换当前单张卡片的监控目标。
13. 作为一名大屏监控值班员，我想要将当前临时切好的船只状态一键“保存为大屏默认配置”，以便于常态化固化监控视角。
14. 作为一名大屏监控值班员，我希望断流或缺失某字段时系统真实展示 `--` 占位符和最后更新时间，而不是用假数据假装系统正常，以便于做出真实准确的指挥决策。

### 4. 核心前端架构与模块划分
- **`src/engine/store/entityStore.ts`**：全局实体池与快照缓存；
- **`src/engine/binding/resolver.ts`**：绑定解析引擎，支持 `sourceMode` 互斥分流与 `controlOverrides` 浅合并；
- **`src/components/controls/`**：7 种原子控件全矢量化（包含 `ImageBox.vue`、`LineChart.vue` 等）；
- **`src/views/canvas/`**：自适应视口缩放引擎（支持 1080P/2K/4K），包含“监控对象侧滑抽屉”与“卡片就地微型切船气泡”。

## 测试决策 (Testing Decisions)

根据项目 `AGENTS.md`“轻量实用，杜绝过度治理”原则，**不引入 UI E2E、Puppeteer 或复杂集成门禁**，全系统只设立**唯一一个极高价值的测试切面（High-Level Seam）**：

### 核心测试切面 (Single Seam): 绑定解析与实体池响应式引擎 (`resolver & entityStore`)
- **测试标准**：只测试公开的输入输出契约行为：
  1. **稀疏覆盖解析正确性**：验证当实例提供 `controlOverrides` 时，私有覆盖项优先于模板默认配置，且未覆盖属性正常继承；
  2. **静态与动态互斥模式**：验证 `sourceMode: "static"` 时推流更新绝不改写显示值；`sourceMode: "dynamic"` 且数据缺失时输出 `--`；
  3. **滑动时间窗口过滤**：验证超出 `lookbackMinutes` 的时序数据点被正确滤除，时效内数据点按时间戳升序排列；
  4. **槽位重定向切换**：验证修改 `slotBindings` 时，解析器瞬间切换指向的新船实体数据。
- **测试模式**：使用 Vitest 编写纯函数单测套件（运行时间 < 1 秒）。

## 范围外说明 (Out of Scope)

1. **复杂 GIS 矢量海图/三维地球**：首版坚决不引入重型 WebGIS 或三维模型，保持纯图表高可靠运行；
2. **未经数据源确认的示意组件**：参考效果图中的船型环图、健康度 100%、雷达测距方位等示意，在未签订数据协议前不纳入首版；
3. **外部重型数据库驱动**：坚决不引入 MySQL、Oracle 等外部数据库软件，保持纯 JSON 文件持久化；
4. **重型构建流水线与 UI 视觉自动化回归测试**：坚决不编写无意义的 DOM 点击测试。
