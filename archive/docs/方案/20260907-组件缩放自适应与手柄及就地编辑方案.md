# 20260907-组件缩放自适应与手柄及就地编辑方案

> **归档说明**:
> - **实施完成日期**: 2026-09-07
> - **验证结论**: 30/30 项单元测试全部绿灯通过，`vue-tsc --noEmit` 0 错误通过；浏览器真实交互验证确认手柄热区扩充至 40px、KPI 卡片属性面板补齐徽标/图片配置、卡片双击就地改字与抽屉文本管理 Tab 均已通过 CDP 自动化与截图验收。

## 问题陈述 (Problem Statement)

用户在日常编排大屏、工坊制作模板以及投屏运行大屏时，面临以下 4 项严重的体验阻碍与功能缺失：

1. **缩放手柄过小极难抓取**：在大屏画布（特别是视口存在缩放比例时）或组件工坊中，卡片和控件右下角的调整尺寸手柄物理像素仅有 11px（缩放后仅 5~7px），且无不可见点击热区扩展，用户用鼠标反复抓取极易点空或误触发卡片选中与拖动。
2. **组件缩放后内部内容不变且挤压**：在工坊或大屏中缩放组件大小时，内部折线图、表格、卡片标题与数值指标的字体及内部排版硬编码了固定像素（如 15px、18px、21px），未做弹性等比缩放；折线图控件缩小后，固定的顶部标签与底部两行长说明占满了全部垂直空间，将曲线图挤压消失且文字相互重叠。
3. **KPI 卡片右侧背景图标无法修改或选不到**：带图标的数值 KPI 卡片右侧的船舶图案属于内置矢量徽标，用户无法用鼠标单选它，且右侧属性检查器（Inspector）彻底遗漏了该徽标的配置入口，导致用户既无法切换内置船型（商船/货船/渔船/告警），也无法上传自己的图片替换。
4. **显示态下无法直接修改文本**：显示态原本采用纯只读设计，隐藏了属性面板并锁定了点击交互，用户在大屏演示或运行态下无法就地修改大屏标题、卡片标题或静态文字；同时右侧监控对象抽屉仅支持换船，无文本修改表单。

## 解决方案 (Solution)

1. **热区倍增与科技感手柄**：
   - 为 `.control-resize` 与 `.card-resize` 引入隐形伪元素判定层，点击热区从 11px 扩充至 38~40px；
   - 视觉手柄增至 14px，加入微发光边框与鼠标悬停放大动效，使鼠标靠近边缘角点即可稳准触发缩放。
2. **相对比例弹性自适应与极小尺寸紧凑模式**：
   - 各原子控件字号改为基于容器比例的相对弹性单位（`em` / 动态字号），卡片拉大文字饱满放大，拉小文字等比精致收缩；
   - 折线图（`LineChart`）引入高度自适应判定：当容器高度低于 130px 时，自动折叠隐藏底部两行辅助说明文字（“实际采样...留白”），释放全部绘图区域，确保曲线走势永远清晰可见。
3. **补齐 KPI 卡片右侧徽标配置项**：
   - 在属性检查器（Inspector）中，当选中 KPI 数值控件时，在外观布局栏明确提供【右侧装饰徽标】设置区：
     - 支持预设图标切换（商船、货船、渔船、告警三角）；
     - 支持上传本地自定义图片（PNG/JPG/SVG，Base64 存储）；
     - 支持选择“无”，完全隐藏徽标。
4. **双通道文本就地修改**：
   - **就地双击编辑**：在编辑态和显示态下，用户双击大屏标题、卡片标题或静态文本即可就地激活输入框，打字改完按回车或失焦即时更新；
   - **抽屉文本通道**：在右侧抽屉提供文本修改视图，集中展示大屏标题与各卡片标题供快速录入；修改后高亮提示未保存，支持快捷键 `Ctrl+S` 持久化保存。

## 用户故事 (User Stories)

1. 作为一名大屏设计者，我想要在鼠标移动到组件或控件右下角附近时就能轻松抓到缩放手柄，以便于快速调整组件长宽而不会反复抓空。
2. 作为一名大屏设计者，我想要在拉大或缩小组件卡片时，内部的标题、图表刻度、数值和表格能等比自适应缩放，以便于大屏在任意尺寸下排版都美观协调。
3. 作为一名大屏设计者，我想要在组件工坊将折线图控件高度缩得很小时，图表自动隐藏底部的冗长辅助文字，以便于保留足够的空间看清曲线走势。
4. 作为一名大屏设计者，我想要在属性面板里给 KPI 卡片切换不同的轮船图标或上传我自己的图片，以便于区分作业渔船、货船与港口标志。
5. 作为一名大屏操作员，我想要在投屏显示态下直接双击某个标题修改错别字或调整名称，以便于在不破坏投屏展示界面的情况下快速完成微调。
6. 作为一名大屏操作员，我想要在右侧抽屉里查看并批量修改卡片标题，以便于清晰核对大屏各个分块的命名并统一保存。

## 实现决策 (Implementation Decisions)

### 1. 缩放手柄判定与样式重构
- 在全局样式中为 `.control-resize` 与 `.card-resize` 增加 `::before` 伪元素：
  - `top: -13px; left: -13px; right: -13px; bottom: -13px;`，热区扩展至 40px；
  - 视觉样式提升为 `width: 14px; height: 14px;`，带有微圆角、科技蓝发光阴影；
  - `:hover` 时赋予 `transform: scale(1.15)` 与高亮青白发光反馈。

### 2. 组件内部弹性缩放与折线图紧凑模式
- **InstanceCard / ControlRenderer 容器比例**：
  - 控件容器注入基准字号与实际尺寸变量，各控件内文本（`.number-label`、`.atomic-table th/td`、`.line-chart` 等）使用 `em` / `clamp(...)` 替代硬编码的固定像素；
- **LineChart 智能紧凑判定**：
  - 监听或计算容器实际高度（或通过高度门槛 `height < 130`），当高度受限时自动通过条件隐藏 `.chart-foot`；
  - 顶部 `.chart-meta` 在超窄宽度下允许紧凑排列，SVG 文本基于视图比例锐利缩放。

### 3. Inspector 补齐 KPI 徽标配置通道
- 在 `Inspector.vue` 中扩展 `variant === 'kpi'` 或 `c.type === 'number'` 的配置项：
  - 增设“右侧装饰徽标”下拉选项：`none`（无）、`vessel`（商船）、`cargo`（货船）、`fishing`（渔船）、`alert`（告警）；
  - 增设“上传徽标图片”文件输入项，复用已有的 1MB 安全 Base64 读取逻辑；
  - `ControlRenderer.vue` 支持渲染用户上传的 Base64 徽标图片，若选择 `none` 则不渲染 `.kpi-emblem`。

### 4. 就地双击文本编辑与抽屉扩展
- **In-situ Text Editing**：
  - 卡片头部 `card-heading strong`、大屏 Banner 标题与静态文本控件增加 `@dblclick` 事件；
  - 激活时切换为轻量内联 `<input>`，聚焦并全选，按 `Enter` 提交、`Esc` 放弃、`blur` 保存；
  - 更新对应的 `instance.title` 或 `control.props.staticValue`，触发 `dirty` 状态；
- **ObjectDrawer 扩展**：
  - 抽屉顶部提供“监控对象调度”与“大屏文本管理”双 Tab 切换；
  - 文本管理 Tab 列出大屏名称及所有卡片标题输入框，可一键批量编辑并点击“保存大屏”。

## 测试决策 (Testing Decisions)

1. **测试边界与标准**：
   - 坚持“轻量实用，杜绝过度治理”红线，不引入重型 E2E / UI 测试；
   - 对核心纯函数与数据流转逻辑编写轻量单测：
     - KPI 控件徽标类型与自定义图片在有效/缺省状态下的属性解析与校验；
     - 卡片标题私有覆盖与静态文本修改在持久化与快照合并时的纯函数安全性；
     - 实例缩放比例因子的计算纯函数。
2. **现有单测保持 100% 通过**：
   - 保证 `tests/core.test.ts` 中既有 30 项核心测试全部绿灯通过；
   - 运行 `npm run typecheck` 保持 0 错误。

## 范围外说明 (Out of Scope)

1. 不引入重型富文本编辑器或富文本标签解析，就地编辑仅针对纯文本字符串；
2. 不允许手动修改由 WebSocket 动态推流过来的物理传感器指标数值（如实时航速数字、时间戳），动态数据源保持只读真源；
3. 不改动 AIS 底账通信协议与数据目录隔离边界。
