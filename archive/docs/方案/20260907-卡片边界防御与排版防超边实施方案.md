# 20260907-卡片边界防御与排版防超边实施方案

> **归档说明**:
> - **实施完成日期**: 2026-09-07
> - **验证结论**: 33/33 项单元测试全部绿灯通过，`vue-tsc --noEmit` 0 错误；双轨构建（离线预编译 `npm run build` + Vite 生产打包 `npm run build:vite`）100% 成功；无头 Edge CDP 端到端自动化脚本（`verify-boundary-clamping.mjs`）对 6 大极限排版与防超边场景（标题截断锁高 45px、编辑态输入框 80% 弹性舒展、副标题 36px 常驻安全呼吸带、下半区换船浮层智能向上翻折、KPI 把手完全外露无裁切、紧凑表格与抽屉超长文本省略截断）全量自动化执行并通过，6 张无损截图已物理落盘至外部临时目录。

## 问题陈述 (Problem Statement)

在经过 Impeccable 专项视觉与技术质量审查后，发现当前低代码大屏在极限排版、超长文本、屏幕边缘及复杂层叠状态下存在 6 处显著的“超边、溢出裁切与视觉遮挡”缺陷：

1. **标题超长导致卡头撑开或文字出界**：卡头主标题与副标题未设置单行弹性比例截断与省略号（`...`）。遇到长名称或小尺寸卡片（如宽度 < 280px）时，文字折行撑高卡头，挤压卡片内部核心监控折线图与数值指标的渲染区域；
2. **就地编辑输入框宽度局促**：双击卡头文字进入就地编辑时，输入框如果同样被锁死在固定窄宽度，输入长文本时会在输入框内部剧烈左右横滚，编辑视野受限；
3. **显示态换船按钮遮挡副标题文字**：在投屏显示态（Viewer Mode）下，鼠标移入卡片右上角时浮现 `⇄` 切换船舶按钮，其绝对定位位置直接覆盖在靠右对齐的副标题文字上方，产生视觉重叠与割裂；
4. **大屏底端卡片换船浮层溢出视口被裁切**：就地换船面板固定向下展开（高度约 200px）。当卡片位于 1080p 画布下半区（如 `y > 750px`）时，展开的弹窗直接掉出大屏底边，由于外层视口具有 `overflow: hidden`，下方船名与“搜索更多对象”按钮被永久裁切且无法滚动点击；
5. **KPI 卡片 `overflow: hidden` 误伤缩放把手与换船浮层**：为了裁切右上角大尺寸半透明背景装饰图，卡片根容器被赋予了 `overflow: hidden`，导致编辑态右下角突出边框的缩放把手（`-8px`）被切掉一半，且展开的换船下拉面板超出卡片高度的部分被彻底切除；
6. **窄卡片表格尾列硬编码与抽屉超长船名挤压**：表格控件时间尾列固定占满 `205px`，在窄卡片下极度挤占数据列；监控对象抽屉内船名超长时未做截断，将右侧物理 MMSI 码和状态徽标推出抽屉边框。

## 解决方案 (Solution)

依据已落盘的领域模型字典（`CONTEXT.md`）与架构决策记录（`docs/adr/0009-card-boundary-defense-and-adaptive-popover.md`），实施全套边界防御与自适应排版策略：

1. **单行弹性截断与悬停提示（Card Boundary Clamping）**：
   - 卡头主标题（`strong`）上限占 60% 宽度，副标题（`.card-meta`）上限占 35% 宽度，超出自动出省略号（`...`）；
   - 卡头高度绝对锁死在 45px，绝不发生纵向折行撑高；
   - 鼠标悬停在截断文字上时，通过原生 `title` 属性呈现完整未截断文本。
2. **编辑态临时自适应扩展（Temporary Input Expansion）**：
   - 双击标题或副标题就地编辑时，激活的输入框临时舒展（最大可占用 80% 可用宽度），保障编辑输入视野开阔；
   - 按回车或失焦保存后，立即收回紧凑展示态并执行单行截断。
3. **全模式像素级位置稳定与避让（Pixel-Stable Uniform Margin）**：
   - 针对声明了对象槽位的卡片，无论处于三栏编辑态还是投屏显示态，副标题右侧统一预留 `36px` 呼吸安全距离；
   - 既彻底根除显示态 `⇄` 按钮与副标题的重叠遮挡，又确保在不同视图切换时副标题文字**绝对零像素横向跳动**。
4. **就地换船浮层智能向上翻折（Smart Flip Popover）**：
   - 系统检测卡片在画布上的垂直逻辑坐标，当下半区（`instance.position.y > 600px`）触发换船面板时，自动添加 `.popover-up` 类，面板由卡片顶部向上翻转展开（`top: auto; bottom: calc(100% + 8px)`）；
   - 彻底杜绝面板超出 1080p 画布底边被物理裁切。
5. **背景装饰独立层隔离裁剪（Emblem Isolation Layer）**：
   - 废除卡片根容器的全局 `overflow: hidden`，恢复卡片 `overflow: visible`；
   - 仅在卡片内部底层建立独立的背景装饰视口，单独对超尺寸背景装饰微标执行圆角裁剪；
   - 确保右下角缩放把手（`-8px`）完整外露高亮，换船下拉面板自由伸展。
6. **紧凑表格尾列弹性收缩与抽屉文本省略**：
   - 表格时间尾列由固定 205px 改为弹性范围 `width: clamp(110px, 34%, 180px)`，配合固定表格布局单行截断；
   - 监控对象抽屉内船名弹性截断，MMSI 与状态徽标固定靠右对齐。

## 用户故事 (User Stories)

1. 作为大屏设计人员，我希望在输入较长的主标题或副标题时，卡头始终整洁对齐且不换行，以便于卡片内部的核心监控图表与表格高度保持稳定、不被挤压变形。
2. 作为大屏设计人员，我希望将鼠标悬停在被省略的标题或副标题上时能看到完整的文字内容，以便于确认具体业务含义。
3. 作为大屏设计人员，我希望在双击修改卡头文字时输入框能舒展展开，以便于看清并编辑长文本内容；保存后自动恢复规整排版。
4. 作为大屏巡视人员，我希望在投屏显示态悬停卡片时，右上角浮现的换船图标（`⇄`）不会盖住右侧的副标题文字，以便于清晰阅读。
5. 作为大屏设计人员，我希望在从“编辑态”切换到“显示态”时，卡头副标题的位置不会向左横向跳跃，以便于大屏预览时视觉绝对稳定。
6. 作为大屏调度人员，我希望点击大屏底部（最下一排）卡片的换船按钮时，下拉面板能自动向上弹开，以便于我 100% 完整看到所有候选船舶并能顺畅点击“搜索更多对象”。
7. 作为大屏设计人员，我希望 KPI 指标卡片右下角的外置缩放把手完整可见，以便于快速拖拽缩放卡片尺寸。
8. 作为大屏设计人员，我希望将包含表格的组件拖拽缩小到较窄尺寸时，表格最后一列不会霸占整个卡片，以便于前置的船名与核心监控指标依然清晰可读。
9. 作为大屏调度人员，我希望在打开右侧全局监控对象抽屉时，长船名不会把右侧的【本船】或状态标签挤出屏幕，以便于列表整齐可读。

## 实现决策 (Implementation Decisions)

### 1. 样式系统防御加固 (`src/styles.css`)

- **卡头标题与副标题单行截断与自适应展开**：
  ```css
  .card-heading strong {
    font-size: clamp(13px, 1.05em, 21px);
    flex: 1;
    min-width: 0;
    white-space: nowrap;
    overflow: hidden;
    text-overflow: ellipsis;
  }
  .card-meta {
    max-width: 38%;
    white-space: nowrap;
    overflow: hidden;
    text-overflow: ellipsis;
    margin-left: auto;
  }
  /* 有槽位的卡片副标题统一预留 36px 呼吸避让带 */
  .has-slots .card-meta {
    margin-right: 36px;
  }
  /* 编辑态临时舒展输入框 */
  .inline-title-input {
    flex: 1;
    max-width: 80%;
    min-width: 120px;
  }
  .inline-subtitle-input {
    max-width: 60%;
    width: auto;
    min-width: 100px;
  }
  ```

- **就地换船面板边缘向上翻转（Smart Flip）**：
  ```css
  .insitu-popover {
    position: absolute;
    z-index: 50;
    right: 12px;
    top: 42px;
    width: min(360px, 95%);
  }
  /* 卡片靠大屏下部时向上展开 */
  .insitu-popover.popover-up {
    top: auto;
    bottom: calc(100% + 8px);
    box-shadow: 0 -10px 35px rgba(0, 0, 0, 0.65);
  }
  ```

- **解除 KPI 卡片全局裁切，构建独立装饰隔离层**：
  ```css
  .kpi-card {
    overflow: visible !important;
  }
  .kpi-emblem {
    position: absolute;
    right: -2px;
    top: 1px;
    width: 116px;
    height: 116px;
    overflow: hidden;
    pointer-events: none;
    border-radius: 0 5px 0 0;
  }
  ```

- **紧凑表格时间尾列与抽屉列表适配**：
  ```css
  .atomic-table th:last-child {
    width: clamp(110px, 34%, 180px);
  }
  .slot-choice strong,
  .object-candidate strong {
    flex: 1;
    min-width: 0;
    white-space: nowrap;
    overflow: hidden;
    text-overflow: ellipsis;
  }
  ```

### 2. 组件模板与交互逻辑微调 (`src/components/InstanceCard.vue`)

- 卡片根节点绑定 `.has-slots` 类（当 `template.slots.length > 0` 时），统一触发副标题的 36px 避让；
- 在展开换船面板时，计算 `instance.position.y > 600`，为 `.insitu-popover` 动态附加 `.popover-up` 类；
- 为 `strong` 和 `.card-meta` 补充完整文本的 `title` 属性。

## 范围外说明 (Out of Scope)

1. **复杂富文本编辑器**：卡头编辑仅支持纯文本与符号输入，不支持 HTML 或富文本混合排版；
2. **多层嵌套下拉菜单**：换船面板保持单层轻量选择与抽屉跳转，不引入多级级联树选择器；
3. **全局网格自动磁吸算法**：本方案专注于单一组件在边界与缩放下的自适应与超边防御，不重写多卡片自动吸附与自动避障引擎。
