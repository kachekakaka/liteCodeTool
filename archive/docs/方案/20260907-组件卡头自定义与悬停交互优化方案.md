# 组件卡头自定义与悬停交互优化方案

## 问题陈述 (Problem Statement)

当前低代码大屏系统在组件卡片头部及换船交互上存在三个显著影响操作体验的缺陷：
1. **悬停误触大弹窗遮挡大屏**：在显示态下，鼠标移入卡片停留超过 400 毫秒就会自动弹出宽达 360px 的“切换监控对象”面板，在大屏巡视浏览时极易引发大面积误触遮挡；
2. **卡头右侧文字无法编辑**：卡片头部的右侧文字被逻辑写死为“目标监控”或“数据总览”，设计人员无法根据业务自定义为“泊位监控”、“能耗统计”等实用标识，也无法彻底清空隐藏；
3. **组件头部配置难以寻找且缺少标题修改入口**：在右侧属性检查器（Inspector）中，一旦用户点击卡片内部的文本、数值或图表，卡片自身的“显示卡头”开关便完全消失；且右侧属性面板无论何时均未提供修改组件主标题与副标题的输入框，导致用户误以为“组件卡头完全不可改”。

## 解决方案 (Solution)

1. **悬停交互收敛（In-situ Retargeting Trigger）**：
   - 彻底删除鼠标悬停 400ms 自动弹出大面板的逻辑；
   - 鼠标悬停在卡片上时仅平滑浮现右上角精致的切换小按钮（`⇄`）；
   - 只有用户**主动点击**该小按钮时，才展开切换监控对象面板；鼠标移出卡片、点击空白处或按 Esc 键关闭面板。
2. **副标题双轨编辑与自由隐藏（Card Subtitle）**：
   - 数据模型扩展支持 `subTitle?: string` 字段；
   - 支持**双轨编辑**：既可以在卡片头部右侧直接**双击就地编辑**，也可以在右侧属性面板的输入框中修改；
   - 允许自由清空：若用户将副标题清空，卡头右侧将**完全隐藏不显示**（不占空间），满足极简卡片视觉需求；若未设置过则保持默认提示（“目标监控”/“数据总览”）。
3. **属性检查器卡头配置常驻置顶（Header Configuration Pinned in Inspector）**：
   - 无论用户当前选中了卡片整体、还是深入选中了内部的具体原子控件，右侧属性检查器的最顶部均清晰常驻【组件头部设置】卡片；
   - 集中提供：☑️ 显示卡头开关、📝 主标题输入框、📝 副标题输入框；
   - 下方紧接着显示当前选中控件的特定属性，彻底根除“找不到卡头在哪改”的困惑。

## 用户故事 (User Stories)

1. 作为大屏观察人员，我希望鼠标在屏幕上随意移动或在卡片上停留时不会自动弹出巨大的换船面板，以便于流畅查阅各项监控数据而不被遮挡视线。
2. 作为大屏操作人员，我希望将鼠标悬停在卡片上时平滑浮现右上角的切换小按钮（`⇄`），点击该按钮时才展开换船面板，以便于在需要时主动、可控地切换监控目标。
3. 作为大屏设计人员，我希望能够双击卡片头部右侧的文字（或在右侧属性面板输入框修改），以便于将默认的“目标监控/数据总览”替换为与业务场景匹配的副标题文本。
4. 作为大屏设计人员，我希望在将副标题文本清空后，卡头右侧完全不留空白占位或默认文字，以便于呈现清爽、现代的纯主标题卡片。
5. 作为大屏设计人员，我希望在画布中点击卡片内任何文字、数值或折线图后，右侧属性面板的最上方依然保留卡头开关和主副标题输入框，以便于我不必先切回组件层级就能随手修改卡头与标题。
6. 作为大屏设计人员，我希望随时可以通过勾选或取消“显示卡头”复选框，快速在有头卡片和无头（Headless）纯净卡片之间切换。

## 实现决策 (Implementation Decisions)

### 1. 数据模型与契约变更 (`src/types.ts`)
- 在 `ComponentInstance` 接口中追加可选字段：`subTitle?: string`；
- 在 `ComponentTemplate` 接口中追加可选字段：`subTitle?: string`（支持组件工坊模板预置默认副标题）。

```typescript
export interface ComponentTemplate {
  id: string;
  name: string;
  category: string;
  layout: { width: number; height: number };
  slots: Slot[];
  controls: Control[];
  showHeader?: boolean;
  decoration?: 'card' | 'banner';
  subTitle?: string;
}

export interface ComponentInstance {
  instanceId: string;
  templateId: string;
  title?: string;
  subTitle?: string;
  position: Geometry & { zIndex?: number };
  showHeader?: boolean;
  slotBindings: Record<string, string>;
  controlOverrides: Record<string, Override>;
}
```

### 2. 卡片悬停与就地编辑交互改造 (`src/components/InstanceCard.vue`)
- **移除自动定时器**：移除 `enter()` 中的 `hoverTimer = setTimeout(() => { popover.value = true; }, 400)`。鼠标移入时不设置任何自动弹窗定时器；保留对右上角 `⇄` 按钮在 `:hover` 下的 CSS 渐显；
- **右上角切换按钮点击**：点击按钮 `@click.stop="popover = !popover"` 打开或关闭弹窗；
- **副标题就地编辑状态**：新增 `editingSubTitle = ref(false)` 与 `subTitleDraft = ref('')`；
- **双击与提交逻辑**：
  - 双击副标题进入编辑态，聚焦于内联输入框；
  - 按 Enter 或失焦触发 `commitSubTitle`，将输入内容保存至 `instance.subTitle`（若在工坊则保存至 `state.draft.subTitle`），同时触发历史记录 `checkpoint()`；
  - 按 Esc 触发 `cancelSubTitle` 放弃修改；
- **副标题显示计算逻辑 (`effectiveSubTitle`)**：
  - 若 `subTitle` 为 `undefined`：采用默认策略，根据 `template.slots.length ? '目标监控' : '数据总览'` 展示；
  - 若 `subTitle` 已被显式设为空字符串（或仅包含空白字符）：通过 `v-if` 完全隐藏该 DOM 节点，不占空间；
  - 若 `subTitle` 为非空字符串：如实展示用户设定的副标题文字。

### 3. 属性检查器常驻卡头面板 (`src/components/Inspector.vue`)
- 在属性检查器模板顶部（无论是选中国家组件还是具体内部控件），统一常驻【组件头部】配置卡片：
  - **显示卡头**：`<input type="checkbox" :checked="headerChecked" @change="header">`；
  - **主标题**：`<input :value="instanceTitle" :placeholder="selectedTemplate.name" @change="changeInstanceTitle">`；
  - **副标题**：`<input :value="instanceSubTitle" :placeholder="defaultSubTitlePlaceholder" @change="changeInstanceSubTitle">`；
- 当选中内部控件时，上述卡头配置保持置顶，下方紧接展示控件的数据与样式配置；
- 在工坊模式（Workshop）与画布编辑模式（Viewer/Editor）下保持逻辑统一。

### 4. 样式与布局调整 (`src/styles.css`)
- 增加 `.inline-subtitle-input` 内联输入框样式，确保就地编辑时背景、边框、字体与 `.card-meta` 协调，不导致卡头抖动；
- 保持 `.view-retarget` 在卡片 `:hover` 时 `opacity: 1`，`:hover` 移出时自然隐去。

## 测试决策 (Testing Decisions)

- **良好测试的标准**：测试重点落在外部公开行为与数据契约，杜绝测试 Vue 内部私有实现细节。
- **关键覆盖模块**：
  1. `src/engine/core.ts`（契约验证）：验证 `validateScreen` 与模板校验允许合法的 `subTitle` 属性，且空值/undefined/自定义文本均能正确序列化；
  2. `npm run typecheck`：全量 TypeScript 类型检查 0 错误；
  3. 运行时 Seam（端到端交互）：使用无头浏览器验证：
     - 鼠标悬停在卡片上超过 1 秒，换船大弹窗**不弹出**；
     - 点击卡片右上角 `⇄` 按钮，换船大弹窗**精准弹出**；
     - 双击卡头右侧副标题，成功进入就地编辑，输入新文字并回车成功保存；
     - 清空副标题后，卡片右侧副标题节点被完全隐藏；
     - 在 Inspector 中点击任意控件，顶部【组件头部设置】依然保持可见，且修改标题即时反映至画布。
- **现有测试先例**：遵循 `tests/core.test.ts` 中基于 `node:test` 的极简轻量单测体系，无重型端到端依赖。

## 范围外说明 (Out of Scope)

- 不引入第三方重型 UI 库或富文本编辑器；
- 不修改 WebSocket 协议与实体数据池字段。
