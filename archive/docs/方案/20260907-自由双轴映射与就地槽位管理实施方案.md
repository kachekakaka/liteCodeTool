## 问题陈述 (Problem Statement)

在平台从 v0.2.0 向更专业的多目标监控与空间态势感知演进过程中，经过用户实际操作体验与 `/grill-with-docs` 专项架构审查，暴露出以下 5 项严重影响设计效率与交互认知的关键问题：

1. **KPI 指标卡文字上下超边出界**：
   - 在卡片根容器恢复 `overflow: visible` 之后，`.atomic-kpi` 控件在计算基础字号（`baseSize: 62px`）时，其大数字样式继承了 `.atomic-number .number-line strong { font-size: 1.55em; }`，导致字体尺寸失控膨胀至 `96.1px`（行高达 `109.55px`）；
   - 加上顶部指标名称（18px）和底部上报时间（13px），垂直总内容高度达到 `168.5px`，严重超出卡片可用高度（`119px`）；
   - 垂直居中后，文字顶部超出上边框 `3px`，底部超出下边框 `6.3px`，直接骑在边框线上，严重破坏大屏科技工业美感。

2. **编辑态卡片右上角悬停换船（⇄）缺失**：
   - `src/components/InstanceCard.vue` 模板中换船按钮与浮层硬编码了 `v-if="viewing && template.slots.length"`；
   - 导致仅在投屏显示态（`viewing`）下鼠标悬浮右上角才会出现 `⇄` 按钮，而在编辑态下无法悬浮换船，用户调试排版时若想预览不同船舶的数据表现，必须频繁往返切换大屏显示态或在复杂的属性面板中逐项指派，操作链路冗长。

3. **工坊制作组件时图例出现真实船名造成模具认知误解**：
   - 在组件工坊（Workshop）设计图表组件模板时，折线图图例直接渲染了系统内置实体（如“远望1号 22.7 节”）；
   - 用户误以为“在工坊做组件时就把具体的船和数据写死了”，无法理解“工坊做的是模具，运行时才给模具填入具体船”的抽象模具设计理念。

4. **多曲线绑定只能选死板的“对象1”且无法就地新建或重命名槽位**：
   - 属性面板（`Inspector.vue`）中折线图数据绑定流程僵化，添加新曲线时默认只能选模板现有的槽位（如果模板只有一个槽位就只能选“对象1”）；
   - 用户无法在曲线配置中直接输入名称新建占位符（如“领航船”、“对比船”），必须被迫先点击画布空白处退到模板根属性面板中声明槽位，再重新点选控件进行绑定；
   - 且数据源未以“数据类型（Data Schema）”作为第一级入口，导致实体数据与全局统计数据混淆。

5. **图表横纵坐标轴僵化锁死，缺乏自由双轴映射与航迹绘制能力**：
   - 现有折线图（`LineChart.vue`）X 轴硬编码为滑动回溯时间轴，Y 轴硬编码为单一时序数值指标；
   - 无法自由选择 X 轴与 Y 轴映射字段（如 X 轴映射经度 `lon`，Y 轴映射纬度 `lat`，或 X 轴映射航速、Y 轴映射油耗）；
   - 缺乏基于时间戳天然时序先后顺序连接空间散点生成船舶航行轨迹线（末端脉冲高亮）的核心态势能力。

## 解决方案 (Solution)

依据已落盘的领域模型字典（[`CONTEXT.md`](../../CONTEXT.md)）与架构决策记录（[`docs/adr/0010-dual-axis-mapping-and-in-situ-slot-management.md`](../adr/0010-dual-axis-mapping-and-in-situ-slot-management.md)），确立全套重构与加固方案：

1. **KPI 指标卡排版防超边闭环约束 (KPI Vertical Bounding Clamping)**：
   - 为 `.atomic-kpi` 建立专用弹性字号与间距约束规则，废除无上限的放大比例；
   - 顶部指标名称限制为 `clamp(12px, 0.28em, 16px)`，margin-bottom 为 4px；
   - 中间大数字强制锁定为 `clamp(24px, 0.82em, 50px)`，line-height 严格收敛至 1.05；
   - 底部上报时间限制为 `clamp(10px, 0.22em, 12px)`，margin-top 为 4px；
   - 容器内容总高由 168.5px 骤降至约 85px，在 119px 容器内自适应垂直居中，上下保留 20px+ 安全呼吸带，超边彻底归零。

2. **全视图模式统一支持就地换船悬停入口 (Universal In-situ Retargeting)**：
   - 将 `InstanceCard.vue` 中的渲染条件从 `viewing && template.slots.length` 解耦放开为 `!workshop && template.slots.length`；
   - 在“编辑态”与“显示态”下，鼠标移入卡片右上角均平滑浮现 `⇄` 按钮，点击即呼出轻量换船面板；
   - 布局空间上，左上角为拖拽抓手（`⠿`）、右上角为换船按钮（`⇄`）、右下角为缩放把手，三者物理坐标完全分离，零视觉与交互冲突。

3. **工坊图例脱敏与模具认知对齐 (Workshop Preview Decoupling)**：
   - 折线图组件检测到处于工坊环境时，图例与文字强制使用抽象占位符别名展示（例如展示为 `【领航船】 22.7 节`、`【对比船】 18.3 节`），坚决隐藏“远望1号”等具体物理船名；
   - 在图表下方或左上角显式标注“模具预览中 · 实际船舶在投屏大屏中指派”，强化设计者的模具抽象认知。

4. **属性面板“数据类型优先”与就地新建/重命名槽位 (In-situ Slot Placeholder)**：
   - 升级属性面板折线图配置流程，确立两级层级：
     - **第 1 级：数据类型（Data Schema）优先选择**：下拉明确区分选择“AIS 船舶目标（实体）”还是“港口总览统计（全局）”；
     - **第 2 级：曲线对象归属与就地槽位管理**：
       - 若为实体类型，曲线归属下拉框展示现有槽位，并提供 `[＋ 新建对象占位符]` 选项；
       - 支持就地输入自定义别名（如“领航船”、“气象伴随船”），系统自动在当前模板 `slots` 数组中注册新槽位；
       - 组件内其他控件（如标题、副标题）即刻共享该新槽位，全流程一气呵成，无需退出控件或切换面板。

5. **自由双轴映射（X/Y 轴自选）与时序航迹线渲染 (Dual-Axis Field Mapping)**：
   - **X 轴基准统一**：
     - 模式 A（默认）：**滑动时间轴**，时间一直往前走，横轴随时间匀速向右推进（近 N 分钟回溯）；
     - 模式 B（自由双轴）：**实体数值字段**（如经度 `lon`），系统统一以该数值为 X 轴映射基准；
   - **多曲线 Y 轴独立度量**：各曲线独立选择 Y 轴字段（如纬度 `lat`、航速 `speed`、主机功率等）及对应对象槽位；
   - **统一时序轨迹动力学模型（Trajectory Line）**：
     - 当 X 轴与 Y 轴均为数值字段时，系统根据底层采样的时间戳先后顺序将 `(X(t), Y(t))` 点对顺次连接成平滑轨迹；
     - 轨迹最新点带有脉冲呼吸光环动画，时间仍在后台持续驱动，新数据推入时轨迹向前自然延伸。

## 用户故事 (User Stories)

1. **作为大屏监控人员**，我希望在 KPI 指标卡中看清数字与单位，且文字绝不骑在或穿透卡片的上下边框，以便于在大屏长时间巡视时视觉舒适、重点突出。
2. **作为大屏搭建人员**，我希望在编辑画布排版时，鼠标移到卡片右上角也能点击 `⇄` 直接切换船舶，以便于我就地验证卡片在不同船舶真实数据下的排版表现，无需频繁切换显示态。
3. **作为组件设计人员**，我希望在组件工坊中制作折线图时，图例显示的是“【对象1】”或“【领航船】”这样的占位符名字，而不是具体的“远望1号”，以便于我明确理解这是一个可复用的通用组件模板。
4. **作为组件设计人员**，我希望在折线图属性面板中，先选好数据类型（如 AIS 船舶），然后在添加曲线时可以直接输入新名字新建一个对象占位符，以便于我无需退回外层即可连续完成多船对比图表的制作。
5. **作为大屏设计人员**，我希望折线图不仅能看随时间变化的速度趋势，还能自由设置 X 轴为“经度”、Y 轴为“纬度”，实时画出船舶的航行轨迹，并且最新位置有脉冲发光效果，以便于直观监控船舶的空间运动。

### 3. 数据类型契约扩展 (`src/types.ts`)

在 `ControlProps` 中增加自由双轴映射支持：
```typescript
export interface ControlProps {
  // ...既有属性
  // 双轴自由映射
  xAxisMode?: 'time' | 'field';       // X 轴模式：'time' 默认时间轴，'field' 实体数值字段
  xAxisField?: string;                // 当 xAxisMode === 'field' 时的数值字段 key（如 'lon'）
  xAxisSlotId?: string;               // X 轴所取样本对应的槽位 id（默认使用首条曲线的 slotId）
  xAxisSchemaType?: string;           // X 轴字段所属数据类型
}
```

### 4. 属性面板“数据类型优先”与就地槽位管理 (`src/components/Inspector.vue`)

- **数据类型优先**：
  提供一个高优先级的模式选择器，用户选择 Schema（例如 AIS 船舶 `ais_vessel` 或 港口统计 `port_stats`）；
- **就地新建与重命名槽位**：
  在曲线槽位下拉列表中：
  - 选项包含当前已有槽位：`<option :value="slot.id">{{ slot.label }}</option>`；
  - 增加动态新增项：`<option value="__new__">＋ 新建对象占位符...</option>`；
  - 选中新增项或就地重命名时，呼出微型文本框输入名称；输入后调用 `createSlot(label, schemaType)`，并在 `selectedTemplate.slots` 中注册 `{ id: uid('slot'), label, schemaType }`；
  - 该曲线的 `slotId` 立即指向该新槽位，卡片其它控件立即同步感知。
- **X 轴与 Y 轴映射面板**：
  - 增加【X 轴坐标基准】：单选切换“滑动时间轴”与“实体数值字段”；
  - 若为数值字段，下拉选择当前 Schema 中的数值字段（如“经度 / deg”）；
  - 每条曲线的度量字段对应为【Y 轴度量字段】（如“纬度 / deg”或“航速 / kn”）。

### 5. 折线图脱敏与双轴时序航迹渲染 (`src/components/LineChart.vue`)

- **工坊图例脱敏**：
  ```typescript
  const isWorkshop = computed(() => state.view === 'workshop' || props.instance.instanceId === 'preview');
  // 图例名称生成
  let label = seriesItem.label || String(record?.data.vessel_name ?? (id || slot?.label || '未绑定对象'));
  if (isWorkshop.value) {
    label = `【${slot?.label || '对象' + (index + 1)}】`;
  }
  ```
- **双轴坐标映射与航迹线算法**：
  - 当 `xAxisMode === 'field'` 时：
    - 读取 X 字段（如 `lon`）与 Y 字段（如 `lat`）的采样点对序列；
    - 计算 X 轴的极值范围 `[xMin, xMax]` 与 Y 轴极值范围 `[yMin, yMax]`（留安全裕量）；
    - 屏幕坐标转换公式：
      `screenX = 58 + ((xVal - xMin) / (xMax - xMin || 1)) * 1116`
      `screenY = 284 - ((yVal - yMin) / (yMax - yMin || 1)) * 238`
    - 生成航迹线 `d="M x0 y0 L x1 y1 ..."`；
    - 最新采样点绘制发光脉冲圆环：
      `<circle class="trajectory-pulse" :cx="traj.lastX" :cy="traj.lastY" r="5" :fill="s.color" />`
    - 横轴刻度从时间切换显示为 X 字段的数值刻度。
